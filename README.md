# Mi Proyecto

## Descripción
Este es un proyecto en donde he realizado la página web de una galería de arte ya existente pero modificándola para que incluya a otros artistas. Me sirve de ayuda para otro proyecto de la universidad.

## Demo en vivo
Puedes ver la demo en vivo aquí: [https://mariaudiez.github.io/web-proyect/portfolio/](https://mariaudiez.github.io/web-proyect/portfolio/)

## Cosas a tener en cuenta
Debido a que para el primer proyecto cree la web a nivel raíz con un index.html, este proyecto actual ha sido creado en la carperta "Opera Gallery" a nivel raíz; esta a su vez está enlazada con el css styles.css (no confundir con el style.css que es el del primer trabajo, enlazado con el index.html que se encuentra a nivel raíz).

En la carpeta "Opera Gallery" se encuentra un index.html en donde se encontrará la homepage del proyecto.

En cuanto al diseño responsive de la web, este proyecto contiene media queries que ajustan el diseño de diversos elementos tales como el footer, a la vez que cumple con el uso de diseño flexible (flex + flex-wrap) para adaptar partes de la web a diferentes tamaños de pantalla. 
También cuenta con contenido multimedia optimizado para diferentes dispositivos, sin embargo, hay algunos elementos que no han sido adaptados debido a complicaciones, ya que al utilizar media queries con ellos, estos se deformaban y alteraban el código inicial de la página. Debido a ello he optado por dejarlos en su código inicial para de esta forma poder mostrar el proyecto en formato web correctamente.
